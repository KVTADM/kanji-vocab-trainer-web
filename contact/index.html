Contact

KVT est développé par une seule personne. Il n'y a pas de service client au sens classique, mais une adresse qui est vraiment lue : kanjivocabtrainer@gmail.com.

Pour quoi écrire ici

Une question sur l'application, ton compte ou l'abonnement Pro. Un bug qui n'est pas lié à un deck précis. Une proposition de partenariat, de presse, ou d'utilisation en cours. Une suggestion d'amélioration.

Pour quoi écrire ailleurs

Un deck qui pose problème (contenu copié, inapproprié, hors sujet) : c'est la page Signaler un contenu qui traite ça, pas cette adresse. Une question déjà courante sur le fonctionnement de KVT : la FAQ y répond peut-être déjà plus vite qu'un échange de mails.

Délai de réponse

Pas de réponse automatique instantanée, mais un vrai suivi : un message est lu et traité, pas mis dans une file d'attente. Compte quelques jours selon le moment. Si tu n'as pas de retour, relance sans hésiter — ça arrive qu'un message se perde.
