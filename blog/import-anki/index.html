Importer son vocabulaire depuis Anki : mode d'emploi

Si tu as déjà des decks Anki ou toute autre liste de vocabulaire, tu peux les importer directement dans KVT plutôt que de ressaisir manuellement.

Étapes :

  1. Va dans la section Vocabulaire.
  2. Prépare ton fichier au format demandé : une ligne par mot, colonnes séparées par point-virgule, dans l'ordre Semestre;Semaine;Kanji;Titre/Mot;Lecture;Sens. Un exemple est affiché directement sur la page.
  3. Colle ton contenu dans la zone prévue, clique "Analyser" pour vérifier que le format est reconnu, puis "Importer" pour valider.
  4. Optionnel : un second import (au format Semestre;Semaine;Kanji;Onyomi;Kunyomi;Bushu;Phrase;Traduction;Memo;Attention) permet d'ajouter les fiches d'aide associées, indépendamment du vocabulaire principal.

Si tu exportes depuis Anki, il faudra reformater tes colonnes pour correspondre à cette structure — un tableur (Excel, Numbers, Google Sheets) fait très bien l'affaire pour réorganiser les colonnes avant de copier-coller.
